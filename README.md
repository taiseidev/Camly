# Camly

![carbon](https://github.com/user-attachments/assets/b8ce6950-afe1-4b67-a9e8-80c155a93c1c)


Camlyは、初心者が写真を学ぶためのサポートや、上級者が知識を共有できる場を提供し、写真の設定や撮影テクニックを発見・共有できるアプリケーションです。

---

## **機能**

### **1. 写真共有**
- 詳細なカメラ設定とともに写真をアップロードして共有。
- ISO、シャッタースピード、絞り値などのEXIFデータを自動で抽出して表示。

### **2. 投稿の詳細設定**
- 写真にタイトルや説明を追加。
- 天気、風景、撮影場所を指定可能。
- 投稿を無料または有料で公開設定可能。

### **3. カメラ設定の共有**
- ISO、シャッタースピード、絞り値、ホワイトバランスなどの設定を共有。
- 使用したカメラやレンズの情報も提供可能。

### **4. マップ機能**
- GPS座標を使用して撮影スポットを地図上に表示。
- 他のユーザーが投稿した写真や詳細情報を地図で探索。

### **5. タグと検索機能**
- シチュエーション、天候、カメラ固有のタグを写真に付与。
- タグ、天候、風景、カメラタイプ別に写真を検索可能。

### **6. ソーシャル機能**
- 他のフォトグラファーをフォローして投稿をチェック。
- 写真に「いいね」やコメントを追加。

### **7. 通知機能**
- 新しいフォロワー、コメント、写真アップロードの通知を受信。
- 通知設定はカスタマイズ可能。

### **8. サブスクリプションモデル**
- 無料プラン: 基本的な写真設定を閲覧可能。
- 有料プラン: 詳細な設定情報とプロフェッショナルの独占アドバイスを閲覧可能。

---

## **使用技術**

- **モバイル**: Flutter
- **Webフロント**: Next.js
- **バックエンド**: Laravel、Firebase、またはその他の技術（予定）
- **データベース**: MySQL（リレーショナルデータベース管理）
- **API**: Google Maps API（位置情報サービス用）, Stripe（決済用）
